Mini-Jeux : Collection de jeux interactifs en Python

Projet personnel - 2024

Application Python avec interface graphique proposant 5 mini-jeux variés

Python Tkinter GUI Jeux PyInstaller POO

Vue d'ensemble

Mini-Jeux est une application Python développée avec Tkinter qui propose une collection de 5 mini-jeux interactifs. L'application est conçue comme une plateforme de jeux avec une interface graphique moderne et un système de gestion des scores intégré.

Ce projet démontre ma maîtrise de la programmation orientée objet en Python, ainsi que ma capacité à créer des interfaces utilisateur intuitives et des systèmes de persistance de données. L'architecture modulaire permet une extension facile avec de nouveaux jeux.

Technologies utilisées

Développement & Interface

  • Python 3.x - Langage principal du projet
  • Tkinter - Interface graphique native
  • Programmation Orientée Objet - Architecture modulaire
  • JSON - Persistance des données et scores

Outils & Déploiement

  • PyInstaller - Création d'exécutable autonome
  • Pathlib - Gestion des chemins de fichiers
  • Git - Gestion de versions
  • JSON - Sauvegarde des scores et configurations

L'application utilise exclusivement des technologies Python natives, garantissant une portabilité maximale et une maintenance simplifiée. L'utilisation de Tkinter permet une interface graphique performante sans dépendances externes.

Architecture du projet

Structure modulaire

Organisation : Le projet suit une architecture modulaire avec séparation claire des responsabilités. Chaque jeu hérite d'une classe de base commune, permettant une extension facile et une maintenance simplifiée.

Pattern de conception

Héritage et abstraction : Utilisation de la programmation orientée objet avec une classe abstraite BaseGame définissant l'interface commune pour tous les jeux. Cette approche garantit une cohérence dans l'interface utilisateur.

Système de gestion

Factory pattern : Implémentation d'un GameManager central qui utilise le pattern Factory pour l'instanciation des jeux. Cette architecture permet une gestion unifiée et une extensibilité maximale.

Persistance des données

Système robuste : Gestion des scores via JSON avec sauvegarde automatique, tri des meilleurs scores et gestion d'erreurs robuste. Le système garantit la persistance des données même en cas de fermeture inattendue.

Structure des fichiers :

  • main.py - Point d'entrée principal de l'application
  • games/ - Dossier contenant tous les jeux et le gestionnaire
  • utils/ - Utilitaires (GUI manager, score manager)
  • assets/ - Ressources (images, dictionnaire, icônes)
  • build_exe.py - Script pour créer l'exécutable avec PyInstaller

Fonctionnalités principales

Interface utilisateur moderne

Menu principal avec navigation intuitive, mode plein écran disponible et fenêtres modales pour chaque jeu. Design professionnel et expérience utilisateur fluide.

Devine le Nombre

Jeu classique où l'utilisateur doit deviner un nombre entre 1 et 100 en 10 essais maximum. Système d'indices "plus grand/plus petit" et score basé sur le nombre d'essais.

Calcul Mental

Jeu de rapidité mathématique avec deux modes : Timer (60 secondes) ou Vies (3 vies, 10 problèmes). Opérations d'addition, soustraction et multiplication. Score basé sur la rapidité de réponse.

Machine à Sous

Jeu de hasard avec 3 rouleaux et 6 symboles différents. Système de paris variable (10-100 crédits) et gains selon les combinaisons : identiques = jackpot, 2 identiques = petite victoire.

Jeu de Frappe

Test de vitesse de frappe utilisant un dictionnaire de 400k mots. Deux modes : Normal (20 mots) ou Timer (60 secondes). Score basé sur la vitesse et la précision de frappe.

Tamagotchi

Jeu d'élevage virtuel avec système de stats (HP, ATK, DEF, MANA, SPD, LUCK). Fonctionnalités : nourrir, jouer, dormir, combats, collecte d'objets. Sauvegarde automatique des données du pet.

Défis techniques relevés

Architecture orientée objet complexe

Conception d'une architecture modulaire robuste avec une classe abstraite BaseGame définissant l'interface commune pour tous les jeux. Gestion de l'héritage et de l'abstraction pour garantir une cohérence dans l'interface utilisateur.

Gestion des événements Tkinter

Maîtrise des événements graphiques complexes : gestion des clics, des timers, des animations et des interactions utilisateur en temps réel. Synchronisation entre l'interface et la logique métier de chaque jeu.

Système de persistance robuste

Développement d'un système de sauvegarde JSON fiable avec gestion d'erreurs, tri automatique des scores et limitation à 10 meilleurs scores par jeu. Gestion des cas d'erreur et de corruption de fichiers.

Optimisation des performances

Gestion efficace de la mémoire avec un dictionnaire de 400k mots pour le jeu de frappe, optimisation des animations et des timers, et création d'un exécutable autonome avec PyInstaller pour une distribution simplifiée.

Architecture modulaire : Organisation claire avec séparation des responsabilités, code réutilisable grâce à la classe de base et facilité d'ajout de nouveaux jeux. Structure maintenable et évolutive.

Interface utilisateur professionnelle

Design cohérent : Interface moderne avec navigation intuitive, feedback visuel pour les actions utilisateur et thème bleu professionnel. Expérience utilisateur fluide et agréable.

Fonctionnalités avancées

Système robuste : Sauvegarde automatique des scores, gestion d'erreurs complète, support du mode plein écran et exécutable autonome créé avec PyInstaller pour une distribution simplifiée.

5 jeux différents : Chaque jeu propose des mécaniques uniques avec système de scores pour la motivation. Modes de jeu multiples (timer/vies) et expérience de jeu complète et engageante.
